# Proovant Security Reviews

Public case studies and remediation outcomes from Proovant's AI-assisted smart contract security reviews.

Proovant uses specialised analysis agents, adversarial validation, and executable Foundry PoCs to help identify and verify security issues.

## Featured Review

### Cloak
Sealed-bid auction and shielded-pool protocol reviewed before mainnet.

- 12 findings reported, each reproduced in Foundry
- 8 fixed by the team
- 1 mitigated
- 3 left as they were: by design, accepted, or testnet-only

[Read the Cloak case study](./cloak/README.md) · [Published review log](https://www.proovant.com/)

### Chordotc
Smart contract and web application security review.

- 9 findings confirmed by the project team
- 3 initial findings fixed
- 6 subsequent findings confirmed
- 4 of the subsequent findings fixed
- 1 already fixed in v2.1
- 1 mitigated

[Read the Chordotc case study](./chordotc/README.md)

**Remediation status:** Based on confirmation from the project team.

## Our Reporting Approach

We aim to provide findings that are:
- Reproducible
- Clearly explained
- Supported by evidence
- Accompanied by practical remediation guidance

Proovant is AI-assisted security analysis and does not guarantee that a codebase is vulnerability-free.
